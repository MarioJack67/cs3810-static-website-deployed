# AI Reflection

## How AI Was Used

To build this project, I used AI to help me set up the boilerplate code for both HTML and CSS. I asked it to give me an html structure that matched the requirements of my webpage including a header, metadata, nav links, sections, and a contact form at the bottom. I used my built in Copilot assistant on my Windows computer to help me build this project.

## Benefits

- Accelerated website development.
- Improved semantic HTML structure.
- Assisted with responsive CSS design.
- Helped organize project documentation.
- Provided guidance on accessibility and user experience.
- Generated examples of Flexbox layouts and media queries.

## Limitations

The usage of AI tools has certain limitations, including the lack of context when asking it to generate CSS. While it can help setup a universal reset and media queries, it doesn't explicitly know what style I'm looking for and the color scheme. So I have to specificy to the AI how I want the style to actually look outside the guidelines for the assignment since LLM's don't do greate without context.

## What I Learned

I've learned that using AI tools in web development can significantly speed up the process of developing a website by removing the repetitive aspects such as HTML structuring and css styling for each unique element. If you provide enough context to the AI, you can perfectly structure the behavior and style of the webpage to exactly as the user imagines it by describing it in detail to an LLM.

# Reflection on AI-Assisted Development

My first prompts was focused on setting up the html page to the specifications of the assignment, as well as structuring it well enough that the CSS would be easy to apply. My next through prompts involved me setting up keep styling details including media queries and a universal reset. Following that, I added some of my own customization to the site by describing the look and feel I wanted on the webpage to the AI. I also troubleshooted some bugs with the navigational link using AI and was able to resolve it quickly. Finally, I had the AI make me a short readme.md file and copy our chat into the prompt log above

Overall, I had a lot of fun working on this webpage because I was able to do a lot of work that would take me days to complete in the course of a few hours. I think that AI is incredibly useful for web development as it removes the basic coding aspects, and allows the main developer to think about the bigger structure, architecture, and style of their project.
