# Academic Portfolio

## Project Description

This academic portfolio website was developed to showcase my technical skills, academic projects, and professional growth as a Computer Science student at Weber State University. The site demonstrates the use of semantic HTML5 elements, modern CSS styling, responsive web design principles, Flexbox layouts, interactive form components, and accessibility-focused navigation.

Featured content includes an About Me section highlighting my background and technical skills, project cards showcasing software engineering and database projects, and a registration/contact form for visitor interaction. The portfolio serves as a centralized location for presenting coursework, development experience, and professional accomplishments.
